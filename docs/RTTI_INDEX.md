# Target middleware RTTI and symbol index

This is a public, path-free index of namespace-qualified strings extracted from
`Block.elf`. It is generated by [`tools/rtti_index.py`](../tools/rtti_index.py)
from the local, gitignored `asm/strings.txt`; the machine-readable table is
[`config/rtti_classes.tsv`](../config/rtti_classes.tsv).

The index is evidence for names, not a class-layout extractor. A hit can be a
demangled RTTI name, an assertion or source-path string, a member path, or a
template argument. `first_line` refers to a line in the local string dump and is
only reproducible with the same dump. The symbol names and occurrence counts are
the durable part.

Regenerate it with:

```sh
python tools/rtti_index.py
```

## Reading the table

- `owner` is the prefix before the final `::`; for a member path it is the
  owning class, not proof that the member exists at a particular offset.
- `leaf` is the final component and is useful for matching reference names.
- `occurrences` counts every regex hit on a line, including duplicate strings.
- `first_line` is a local dump coordinate, not a binary address or a source line.
- The index deliberately excludes FFL. FFL evidence is tracked separately in the
  middleware audit because the target exposes mostly resource names and only a
  few class identifiers.
